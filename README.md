# desktop-auto-organizer-kiro





\# Desktop Auto Organizer with Kiro



\## Problem

“I hate having a messy desktop, so I built this.”



My desktop gets filled with screenshots, PDFs, photos, and random files.

Sorting them manually every day is boring and repetitive.



\## Solution

A simple automation using Kiro that organizes all files into structured folders automatically:



\- Images → Pictures/

\- Documents → Documents/

\- Videos → Videos/

\- Zip files → Archives/

\- Others → Misc/



\## How Kiro Helped

Kiro allowed me to quickly test and iterate on the logic using its scripting and file system hooks.

Instead of manually writing complex shell scripts, I used Python directly and validated the workflow

inside the Kiro platform.
